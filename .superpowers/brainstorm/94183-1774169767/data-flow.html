ToKaWalk — Conversation Loop

What happens from "Hey Toka" to the AI speaking back

1
WAKE WORD — Porcupine detects "Hey Toka" passively (low CPU). Wakes app from idle.
↓
2
STT — Native OS mic opens. Records until silence detected (~1.5s pause). Transcribes to text.
↓
3
CONVERSATION ENGINE — Appends user turn to context. Applies session mode prompt (Brain Dump / Journal / Learn). Routes to LLM.
↓
4
LLM — Local (Llama 3.2 3B via llama.rn) or Cloud (Llama 3.1 8B via Groq). Streams response tokens back.
↓
5
TTS — Native OS TTS speaks the response aloud. Streams sentence-by-sentence for low latency feel.
↓
6
PERSIST — Full turn (user + AI) saved to SQLite. On session end: LLM generates summary, also saved locally.
↓
↺
LOOP — Returns to listening state. "Hey Toka" triggers next turn. Tap-to-talk available in Chat Mode.
SESSION END
User says "Bye Toka" or taps End → Engine finalises transcript → LLM generates summary → both saved to SQLite → app idles
