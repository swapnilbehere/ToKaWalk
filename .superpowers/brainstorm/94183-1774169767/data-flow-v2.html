ToKaWalk — Conversation Loop v2

Wake once, talk freely, barge-in anytime

⏸
IDLE — Porcupine passively listens for "Hey Toka" only. Minimal CPU, battery friendly. App can be screen-off.
↓ "Hey Toka" detected
▶
SESSION START — User picks mode (Brain Dump / Journal / Learn) or uses last-used mode. VAD activates. No more wake word needed.
↓ enters conversation mode
CONVERSATION MODE LOOP
VAD
LISTENING — VAD detects user starts speaking. Threshold tuned slightly higher outdoors (wind/traffic guard).
↓ speech detected
STT
TRANSCRIBE — Native OS STT captures until ~1.5s silence. Sends text to Engine.
↓
LLM
GENERATE — Local Llama 3.2 3B or Groq 8B. Streams tokens. Engine sends to TTS sentence-by-sentence.
↓ streams sentences
TTS
SPEAK — Native OS TTS speaks. AEC active (OS-level). VAD still listening in background for barge-in.
↓ AI finishes speaking
→ Back to LISTENING state
↓ user talks over AI (barge-in)
TTS stops · partial response kept in context · STT captures correction · LLM responds knowing what it was mid-saying
↓ "Bye Toka" or tap End
■
SESSION END — Full transcript saved to SQLite. LLM generates summary (local, no cloud needed). App returns to IDLE.
BARGE-IN NOTES
  • Earbuds use case: echo problem eliminated (audio in ear, not in room)
  • Speaker use case: OS-level AEC filters speaker audio from mic input
  • VAD sensitivity: tunable setting — higher threshold outdoors (wind/traffic), lower indoors
