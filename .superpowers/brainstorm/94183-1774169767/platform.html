First question: Which platform approach?

This affects the entire tech stack — pick the approach that fits your situation best.

A

React Native

One JavaScript/TypeScript codebase for both Android & iOS. Large ecosystem, good offline LLM support via native modules. Fastest to ship for a solo dev or small team.

Pros

  • Single codebase
  • Large community
  • Good LLM bindings available

Cons

  • Bridge overhead
  • Some native quirks
B

Flutter

Dart codebase, compiles to native. Fast rendering, growing LLM plugin ecosystem. Great UI consistency across platforms.

Pros

  • Native performance
  • Consistent UI
  • Growing ecosystem

Cons

  • Dart learning curve
  • LLM plugins still maturing
C

Native (Android first, iOS later)

Start with Android (Kotlin), ship iOS (Swift) later. Best performance, full control over on-device LLM integration.

Pros

  • Best performance & control
  • Direct hardware access
  • Best LLM integration

Cons

  • Two codebases eventually
  • Slower to ship cross-platform
